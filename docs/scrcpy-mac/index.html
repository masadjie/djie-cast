Djie Cast / Panduan · English

scrcpy di Mac, tanpa terminal.

scrcpy adalah cara terbaik menampilkan dan mengontrol HP Android dari komputer, tapi di Mac biasanya harus dipasang lewat Homebrew dan dijalankan dari terminal. Djie Cast membawa scrcpy dan adb di dalam aplikasinya, jadi kamu cukup colok kabel dan tekan satu tombol.

Langkah-langkahnya

  1. Unduh Djie Cast

    Ambil file DMG terbaru dari halaman rilis GitHub, lalu seret Djie Cast ke folder Applications. scrcpy dan adb sudah ada di dalamnya.

  2. Aktifkan USB Debugging

    Di HP: Pengaturan → Tentang ponsel → ketuk Nomor build 7 kali, lalu buka Opsi pengembang dan nyalakan USB Debugging.

  3. Colok kabel dan izinkan

    Sambungkan HP ke Mac, lalu ketuk Izinkan pada dialog “Izinkan USB debugging?” di HP.

  4. Tekan Mulai Cast

    HP muncul sebagai kartu di halaman Android. Satu klik, jendela HP terbuka dan langsung bisa dikontrol dengan mouse dan keyboard.

Semua opsi scrcpy, tanpa menghafal flag

Kualitas video, bitrate, fps, audio, matikan layar HP, tetap menyala, tampilkan sentuhan, selalu di atas, layar penuh, dan rekam layar tersedia sebagai tombol dan sakelar. Pengguna lanjutan tetap bisa menambahkan argumen sendiri.

Lebih dari sekadar mirror

Kartu perangkat menampilkan spesifikasi HP, kondisi dan siklus baterai, serta sisa penyimpanan. Ada juga file manager Android, daftar aplikasi dengan tombol uninstall, dan mode kamera HP.

Pertanyaan umum

Apakah perlu memasang scrcpy lewat Homebrew?
Tidak. Djie Cast sudah membawa scrcpy dan adb resmi di dalam aplikasinya.
Apakah bisa lewat Wi-Fi?
Bisa. Colok sekali lewat USB, aktifkan mode Wi-Fi dari kartu perangkat, lalu kabel boleh dicabut.
Apakah Djie Cast gratis?
Ya, gratis dan open source dengan lisensi MIT.

Mac to Mac remote desktop, free.

Need to help family or reach your office Mac from home? Djie Cast has a Mac to Mac remote desktop that works like AnyDesk, without an account, without a relay server, and for free.

Download for MacSee all features

Step by step

  1. On the Mac to be controlled

    Open Remote Desktop, turn on Allow this Mac to be accessed, and grant Screen Recording and Accessibility.

  2. Share the code

    A 6-digit code appears. You can change it any time.

  3. On the controlling Mac

    Macs on the same network appear automatically. Pick one, enter the code, and connect.

  4. Over the internet

    Sign in to Tailscale once on both Macs. After that, Macs on any network can connect.

Secure from the start

The connection is TLS-encrypted with a key derived from the access code, and wrong codes are rejected. A controlled Mac always shows a red panel with a Disconnect button.

Feels local

Video is H.264-encoded by the Mac's hardware. Mouse, right-click, scrolling, keyboard and ⌘ shortcuts go straight to the other Mac.

Questions

Can I connect from Windows?
Not yet — Mac to Mac only for now.
Does it go through a Djie Cast server?
There is no Djie Cast server. On a local network the connection is direct; over the internet it uses your private Tailscale network.
Why does it keep asking for permission?
macOS asks for Screen Recording and Accessibility once. If it still says Not yet after allowing, use Reset permissions on the Remote Desktop page.

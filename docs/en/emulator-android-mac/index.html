Android emulator on Mac, no Android Studio.

Android Studio is a big download if all you need is an emulator to try an app or game. Djie Cast downloads only the parts you choose, creates the emulator, and runs it with hardware acceleration.

Download for MacSee all features

Step by step

  1. Open the Android Emulator page

    Under Components, download Android Emulator and one system image, for example Android 15 with Google Play.

  2. Set up the device

    Pick a phone, small phone or tablet, then choose RAM, cores and storage.

  3. Create the emulator

    Press Create emulator. Its configuration is stored in Android's standard location, so Android Studio can read it too.

  4. Run it

    Press Run. Once booted, the emulator gets a spec card and can be cast right away.

Downloads you can trust

Everything comes from Google's official repository, is checksum-verified, and shows its license before download. Downloads are cached so you don't fetch them twice.

Made for Apple Silicon

arm64 system images run natively on M-series chips, with the Mac GPU and Quick Boot, so they start in seconds.

Questions

Can I get the Play Store?
Yes, choose a Google Play system image.
How much space does it need?
About 2 to 3 GB per Android version, plus the emulator storage you choose.
Can I use it alongside Android Studio?
Yes. Djie Cast uses the same SDK location, ~/Library/Android/sdk.

Cara mirror HP Android ke Mac.

Dengan Djie Cast, layar HP Android tampil di Mac dalam hitungan detik, dan kamu bisa mengontrolnya dengan mouse dan keyboard Mac. Cocok untuk presentasi, demo aplikasi, live streaming, atau sekadar membalas chat tanpa mengangkat HP.

Download untuk MacLihat semua fitur

Langkah-langkahnya

  1. Pasang Djie Cast

    Unduh DMG, seret ke Applications. Pembukaan pertama: klik kanan → Open.

  2. Nyalakan USB Debugging di HP

    Pengaturan → Tentang ponsel → ketuk Nomor build 7 kali → Opsi pengembang → USB Debugging. Di HP Xiaomi, nyalakan juga “USB debugging (Pengaturan keamanan)”.

  3. Sambungkan kabel

    Pakai kabel data, lalu ketuk Izinkan di HP. Centang “Selalu izinkan dari komputer ini” agar tidak ditanya lagi.

  4. Mulai cast

    Buka halaman Android di Djie Cast dan tekan Mulai Cast. Untuk Wi-Fi, pilih Aktifkan Wi-Fi di menu kartu, lalu cabut kabel.

Keyboard Mac jadi remote HP

⌘B kembali, ⌘H home, ⌘S aplikasi terbaru, ⌘↑ dan ⌘↓ volume, ⌘R putar layar, ⌘V tempel teks dari Mac ke HP. Klik kanan juga berfungsi sebagai tombol kembali.

Untuk OBS dan live streaming

Jendela cast bisa ditangkap OBS, Streamlabs, atau Ecamm Live lewat Window Capture. Nyalakan “Tanpa bingkai jendela” untuk gambar yang bersih.

Pertanyaan umum

HP tidak terdeteksi, kenapa?
Biasanya USB Debugging belum aktif, kabel hanya untuk mengisi daya, atau dialog izin di HP belum diketuk. Djie Cast punya panduan langkah demi langkah di halaman Android.
Apakah suaranya ikut?
Ya, untuk Android 11 ke atas audio HP ikut diteruskan ke Mac.
Apakah HP perlu di-root?
Tidak perlu root dan tidak perlu memasang aplikasi apa pun di HP.
